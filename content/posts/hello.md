这是我第一次正经写博客。想了很久要拿它干什么，最后决定**不设主题**——想写什么写什么，技术、生活、踩过的坑都算。

> 这段自我介绍是占位的，你可以随时在后台改掉。

## 这里有四个板块

导航栏上那几项，简单说一下：

| 板块 | 是什么 |
|---|---|
| 📰 **要闻** | 每天早上 7 点自动汇总的国内要闻。含「每日 60 秒」速览和中新网、界面新闻、少数派三个来源 |
| ✍️ **文章** | 就是你正在看的这类东西 |
| 🎮 **小游戏** | 羊了个羊、合成大西瓜、2048、贪吃蛇。纯前端，不用登录，最高分存在你自己的浏览器里 |
| 🛒 **薅羊毛** | 实时汇总的好价，数据来自什么值得买，每 10 分钟刷新一次 |

## 这个网站是怎么搭起来的

这部分可能有点意思，因为它**没有服务器、没有数据库、没有花一分钱**。

它其实是一堆静态文件：我写 Markdown → 推到 GitHub → Netlify 自动构建成网页 → 分发到全球 CDN。整个过程没有任何一台需要我维护的机器。

好处是：

- **不会宕机**——没有服务器可以挂
- **不怕被攻击**——没有数据库可以黑
- **成本为零**——静态托管是这个行业的常规做法，不是补贴，不会哪天突然收费
- **内容永远是我的**——文章就是一堆纯文本，躺在自己的 Git 仓库里，随时能整体搬走

代价是不能跑 WordPress 那套插件，不过对个人博客来说无所谓。

### 几个还在自动跑着的东西

- **首页背景**每天自动换成 Bing 当日壁纸
- **每日要闻**由 GitHub Actions 在北京时间早上 7 点自动抓取
- **薅羊毛**由 Netlify 的函数实时抓取，带 10 分钟缓存

## 关于更新频率

**不承诺。** 想写就写，不想写就不写。

我见过太多博客开在「我要每周更新一篇」的flag上，然后一个月后再也没动过。所以这里不立 flag。
