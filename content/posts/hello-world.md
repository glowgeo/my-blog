欢迎来到你的新博客 🎉

你现在看到的这个页面，是由一条完整的流水线自动生成的：

```
你的文章（Markdown）
      ↓  存进 GitHub 仓库
GitHub 仓库
      ↓  推送触发
Netlify 自动构建（Hugo）
      ↓  生成静态文件
你的网站（全球 CDN 加速）
```

这条流水线上**没有任何一台服务器、没有数据库、没有一分钱支出**，也**不需要信用卡**。

## 这套方案意味着什么

**好处：**

- 成本为零，而且不是"暂时免费"——静态托管是这个行业的常规做法，不是补贴
- 不会宕机，CDN 分发，访问速度比大部分小服务器快
- 不怕被攻击，没有后台数据库可以黑
- 文章以纯文本存在你自己的 GitHub 仓库里，随时能整体搬走
- 你依然有一个图形化后台，**不需要懂 Git 也能写文章**

**代价：**

- 不能用 WordPress 的插件生态
- 不能跑 PHP / MySQL 那一套后端程序

对个人博客来说，这些代价基本可以忽略——评论、搜索、统计、图片，全都有免费的替代品。

## 接下来做什么

1. 打开 `/admin/` 就能进入写作后台（部署完成后）
2. 把这篇示例文章删掉，或者改成你自己的第一篇文章
3. 去 `hugo.yaml` 里把标题、简介、作者改成你自己的

如果过程里卡住了，看看站点根目录下的《上线操作指南》，每一步都写清楚了。

> 写下去，比写得好看重要得多。
